# Explainability and Audit Specification

GitRealAudit provides transparent, auditable explanations for all security evaluations and policy decisions.

## Decision and Policy Reasoning Protocol

GitRealAudit evaluates real estate investments using a deterministic property cash flow model and financial covenant verification engine. When property income statements or tenant leases are submitted, the agent calculates gross revenues, operating expense ratios, and debt coverage multiples against institutional underwriting guidelines. If an asset exhibits an inadequate DSCR buffer or unverified lease escalations, the agent flags an immediate investment risk. The evaluation logic is completely deterministic and reproducible across all operational environments.

## Data Sources and Ingestion Inputs

The data sources consumed by GitRealAudit include property operating statements (Schedule E / T12), rent roll schedules, commercial mortgage term sheets, and local municipal property tax records. It references institutional real estate appraisal methodologies. These inputs enable rigorous mathematical underwriting of commercial real estate. All incoming configuration files and metadata objects undergo strict schema validation before processing.

## System Limitations and Known Constraints

GitRealAudit performs financial underwriting analysis and cannot conduct physical environmental soil site assessments or structural engineering inspections. It assumes historical operating statements submitted by property sellers are audited and accurate. Highly specialized ground lease negotiations require specialized municipal land-use legal review. Users must ensure that complex architectural changes receive secondary review from certified domain specialists.
